Each simulated device is a separate process running the PWA's own code (local database, sync queue, sync manager and API client) against the real API and a throwaway PostgreSQL database. The app's own timings apply: after reconnecting it waits 5 s and sends its queue; while records are still waiting it retries automatically (5 s after a sync that got some through, then 15 s, 30 s, 1, 2 and 5 minutes while nothing does). A dropped connection does not count as a failed attempt; an operation the server rejects is marked failed after 3 retries. The automatic sync is left alone for up to 3 minutes; users press "Sync now" (at most 3 times) only if records are still waiting after that.
